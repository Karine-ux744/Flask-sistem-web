# 🌐 Site com Flask

Projeto desenvolvido com **Flask** como parte do meu processo de aprendizado em desenvolvimento web com Python.

O objetivo deste projeto é construir uma aplicação web completa, aplicando boas práticas de desenvolvimento, organização de código, controle de versão com Git e GitHub e conceitos utilizados em projetos profissionais.

---

# 🚀 Funcionalidades

## ✅ Implementadas

* Página inicial
* Página de login
* Página de cadastro
* Navegação entre páginas
* Templates com Jinja2
* Template base (`base.html`)
* Barra de navegação reutilizável
* Layout responsivo
* Controle de versão com Git

## 🔜 Em desenvolvimento

# ▶️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone <url-do-repositório>
```

### 2. Entre na pasta do projeto

```bash
cd "Site com Flask"
```

### 3. Crie e ative o ambiente virtual

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 4. Instale as dependências

```bash
pip install -r requirements.txt
```

### 5. Execute a aplicação

```bash
python app.py
```

### 6. Abra no navegador

```
http://127.0.0.1:5000
```
